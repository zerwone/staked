# staked reference

Everything the README leaves out.

## Data model

```
agents/
  roles.yml          single source of truth: owner, boss, agents (status, lane globs, reviews), rules, resources
  board.jsonl        append-only task events; latest event per task wins
  questions.jsonl    append-only owner-decision ledger
  DECISIONS.md       numbered owner decisions (D-001), hand-written by the owner, append-only
  HISTORY.md         one line per handover                                       (generated)
  BOARD.md           open tasks, newest first                                    (generated)
  locks/<name>.lock  claim and resource locks with agent and TTL                 (git-ignored)
  inbox/<agent>/     specs, with frontmatter: task, owner, status, allowed_paths, done_when
  reports/           <task>-<agent>.md, frontmatter: task, agent, flags, tests_run, native_boot, files_changed
  specs/             shared interface contracts (change these first)
  archive/           pruned specs and reports
```

`roles.yml`:

```yaml
owner: alex
boss: claude-code
agents:
  claude-code:
    status: active          # active | paused | retired
    lane: ["api/**", "db/**"]
    reviews: ["cursor"]
  cursor:
    status: active
    lane: ["web/**"]
    reviews: ["claude-code"]
rules:
  - claim before start, one task at a time
  - never edit another lane's files
  - shared interfaces change in agents/specs first
  - nobody approves their own work
  - no deploy, push or migration without owner go
resources: ["staging-db"]   # lockable named resources
```

A board event: `{"ts":"2026-11-08T12:00:00Z","task":"T-101","agent":"cursor","status":"DOING","note":"...","flags":[]}`. Statuses: `TODO DOING BLOCKED REVIEW DONE PAUSED STOPPED`.

A question: `{"ts":"...","id":"Q-031","agent":"cursor","text":"...","blocking":["T-101"],"default":"keep flags off","expires":"2026-11-10","status":"open","answer":null}`.

Generated files carry `<!-- generated by staked, do not edit -->` and a content hash, so a hand edit is caught by `staked check` and `staked doctor`. The two `.jsonl` logs are marked `merge=union` in `.gitattributes`, so parallel branches never conflict on them.

## Commands

| Command | Job |
| --- | --- |
| `staked init [--agents a,b] [--owner name]` | Scaffold `agents/`, write a `roles.yml` template, add `merge=union` for the logs, print next steps |
| `staked gen [--force]` | Regenerate `CLAUDE.md`, `AGENTS.md`, `.cursor/rules/staked.mdc`, `GEMINI.md` (only for agents that read them) plus `agents/BOARD.md` and `agents/HISTORY.md`. Each context file holds that agent's role, lane, open tasks, open questions it owns and the rules, under 6 KB |
| `staked claim <task> --as <agent>` | Start a task. Refused if another agent holds it, if you already have a DOING task, or if you are paused. Writes `locks/<task>.lock` (TTL 8h, `--ttl`) |
| `staked status <task> <STATUS> --as <agent>` | Move a task. `REVIEW` needs a valid report whose `files_changed` match the real diff; `DONE` needs a different agent who reviews the author (or the owner) |
| `staked release <task>` | Give a task back (TODO) and drop its lock |
| `staked lock <resource> --as <agent> [--ttl 2h]` / `staked unlock` | Mutex for a shared resource from `roles.yml`. Refused while held and not expired |
| `staked board [--all] [--json]` | Open tasks, newest first, one row per task |
| `staked ask` / `staked answer Q-031` / `staked questions open` | The owner ledger. `questions open` prints only unresolved entries, most-blocking first, then oldest, two lines each |
| `staked check [--as <agent>] [--staged]` | Pre-commit gate: refuses paths outside the committer's lane, code without a claim, board rows written for someone else, hand-edited generated files, and REVIEW without a valid report. Lanes are read from `HEAD`, so a commit cannot widen its own lane. `--commit <rev>` replays history |
| `staked hook install` | Writes `.git/hooks/pre-commit` running `staked check`; an existing hook is kept and runs first |
| `staked handover <from> <to> [--lanes all\|list]` | Rewrite `roles.yml` (lanes and/or boss), log a `HISTORY.md` line, regenerate. Refused while `<from>` is DOING unless `--force-release` (marks it PAUSED) |
| `staked report check <path>` | Validate a report's frontmatter against the git diff |
| `staked prune` | Archive closed specs and reports of tasks DONE more than 14 days ago |
| `staked doctor [dir]` | Find stacked authority sections, duplicate task ids, hand-edited generated files, lane overlaps, expired locks, expired unanswered questions, agents with more than one DOING task, reports without `flags`. Also runs on a legacy `agents/` folder with no `roles.yml` |

Identity is `--as <agent>`, else `$STAKED_AGENT`, else `git config user.name`. The owner named in `roles.yml` is exempt from lane checks.

## What staked is not

- **Not messaging.** Agents do not talk to each other through staked; they read files.
- **Not orchestration.** staked does not start, schedule or route agents.
- **Not transcript import.** It never reads or stores agent sessions.

It is the layer those tools do not have: who may do what, who decided what, and whether the files agree.
